# 检测端串口扫码服务

安装在接扫码枪的 Windows 检测电脑；202 仍运行原有容器系统。扫码枪 → 本机 Windows 服务 → 配置的服务地址 `/api/mobile/upload/json` → 服务器生成二维码并通过 `mobile_upload/mobile_passcode` 推送 → 已打开的系统页面按原14段协议回填。服务不依赖浏览器焦点，不操作检测、预约、栏杆或 X 光。

双击 `1-安装并开机启动.cmd`，在 Windows 管理员提示中允许安装。服务自动启动并设置开机运行；桌面生成“绿通扫码服务管理”快捷方式。原生 .NET Framework 程序，无需安装 Python、浏览器插件或串口驱动以外的第三方运行环境。

双击 `ScannerBridge.exe` 或桌面快捷方式，可修改目标 IP/域名、端口、串口、波特率及字符编码。目标地址填写系统根地址，例如 `http://192.168.88.202:5173`；迁移网络后改地址并点击“保存配置并重启”。可以先点击“测试目标连接”。HTTPS 使用 Windows 的正常证书校验，需先信任服务端证书。

默认当前扫码枪为 COM7、115200、8N1，UTF-8/GBK 自动识别。若设备不同，安装前先打开管理程序选择正确串口。保存时记录所选 USB 设备身份，重插后 COM 号变化可自动匹配同一设备；不会打开占用旧 COM 号的其他设备。串口参数为8数据位、无校验、1停止位、无流控。

提供独立“启动服务”“停止服务”“重启服务”“卸载服务”双击入口，也可直接在管理窗口操作。服务名 `LvTongScannerBridge`，安装至 `%ProgramData%\LvTongScannerBridge`；配置 `scanner-config.xml`，状态 `status.json`，日志 `scanner.log`（限长轮转）。卸载停止读取并取消开机自启；保留配置及有限日志，方便重装。需要彻底移除文件时，关闭管理程序后可手工删除该目录。

支持回车、换行、STX/ETX和400ms静默分帧，完整帧后再解码，避免中文分字节损坏。只上传有效完整通行码，3秒内相同码去重。网络失败最多重试3次，同一次扫描固定文件名避免重试重复派发；超过20秒的排队码直接丢弃，不在之后的车辆业务里补发旧码。失败时查看状态并重新扫描。串口拔插/占用时自动重连，服务异常退出由 Windows 自动重启。服务端接收成功不等同于页面已收到；页面须已登录且与服务器实时连接。

源码构建：在 Windows PowerShell 运行 `./build.ps1`，输出 `dist/`。自检：`ScannerBridge.exe --self-test`，结果写 `self-test-result.txt`，仅使用本地随机HTTP端口，不访问现场。
