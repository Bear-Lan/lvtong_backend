# 车身点云示范文件

`vehicle.laz` 是用户于2026-11-07提供的示范数据（138042字节、LAS1.2 / format3、48852点），用于实时点云尚未返回时临时展示车顶/车侧投影。

- XYZ按LAS头scales/offsets解码；当前坐标单位按米配置。XY投影为车顶、XZ为车侧，X方向保留车长。
- RGB字段均为0，因此投影统一使用蓝色点、白色背景。
- 同一份文件只解压一次生成两幅无损PNG，默认0.01米/像素；最长边超过4096时两图一起调整比例。
- 实时接口 `RADAR_POINT_CLOUD_URL` 默认5001/geom/laz，返回有效LAS/LAZ时优先采用。无效/失败时回退示范并明确标注来源。
- 设置 `RADAR_POINT_CLOUD_SAMPLE_FALLBACK=false` 可关闭回退。示范图不作为前端正式记录的车顶/车侧图片提交。
- 预约图仍走5001/appt/image，不混用这个示范文件。
