# AI正式服务接入

2026-11-19：车轴/车厢、实拍货品推荐、行驶证裁剪、OCR及掩码装载率使用统一客户端 `app/services/ai_client.py`。雷达目标、透视区域及分类不启用。此前数据库中的AI_DETECT_URL、AI_LICENSE_CROP_URL、AI_LOAD_RATE_URL、OCR_SERVICE_URL属于旧协议地址，不再控制上述新版调用。

## 连接配置

后端读取 `config/ai.local.json`，此文件已Git忽略。默认正式地址 `https://192.168.188.151:8891`，公证书为 `certs/ai-server-public.pem`。配置文件格式：

```json
{
  "base_url": "https://192.168.188.151:8891",
  "username": "station",
  "password": "在本机填写业务口令",
  "ca_bundle": "证书的绝对路径"
}
```

`ca_bundle`省略时使用随代码保存的公证书。用户名和密码也可由环境变量 `AI_USERNAME`、`AI_PASSWORD`提供；其他可覆盖项为 `AI_BASE_URL`、`AI_CA_BUNDLE`、`AI_CONFIG_FILE`。`AI_PROXY`仅用于开发机经授权通道验证，不应携带到现场部署。环境优先于本机文件。

部署时应挂载该私有配置文件并设置AI_CONFIG_FILE，或通过部署环境注入凭据；不要将口令放进代码、前端或普通配置API。开发机账号仍以工作区的“本地凭据/账号密码.txt”为维护来源，本机运行文件只是应用读取副本。连接配置在请求时读取，无需通过设备初始化加载。

HTTP重定向不跟随，TLS及地址校验保持开启。所有推理要求HTTP200和整数code=1，本系统API仍code=0成功；识别失败返回502。请求号、接口路径、耗时写日志，超过2秒标为warning/over_2s=True，便于追溯。日志不记录认证和图片内容。网络/模型失败不自动无限重试。

## 业务使用

- 车身图到位后自动识别车轴和车厢。车型继续使用车轴+车牌颜色旧规则，页面按最新车牌颜色重算两轴车型。
- 实拍货物照片逐张识别，多图同品保留最高置信度。class_id如pingguo先通过确定的中文名称映射，再精确匹配农产品字典；未知或歧义类别不模糊套用其他产品。
- 农产品选择窗口按推荐置信度优先排列，推荐排序在后端分页之前完成；可搜索、筛选、多选。模型置信度不等同准确率，不自动选择或覆盖已有货品。
- 行驶证上传主车/挂车分开的图片，每台车的一张图片须包含其正、副页。兼容裁剪仍走/detect，task=truck_real，传crop_image1和可选crop_image2。主挂拼接仅展示/保存；OCR只接收主车正、副页。裁剪失败保留原图并继续尝试OCR；弹窗显示结果及重试入口。
- OCR补空车牌，也可更新尚未人工修改的旧AI车牌；人工确认或主动清空后不覆盖。车牌来源独立于当前裁剪图记录，避免换图或重试冒用旧标记。出口称重仅显示参考区间，不自动填写实际称重。
- AI补填的车牌、车型、货箱类型用小“AI”标记；货物全部从当前AI推荐确认时也标记，裁剪图显示“AI裁剪”，重量范围显示“AI参考”。人工改值后清标，换图/切车防止沿用旧标记。当前检测的`aiMarks`按字段随草稿同步，图片来源统一规范为共享URL；不扩展历史业务记录结构。无标记也可能是手工/历史值，不能据此单独判定接口失败。
- 装载率使用拼接图，缺少拼接图时用200图；连续出图空闲1.2秒后计算。读取顶层mask_image.base64，沿用原中/底部分区加权规则。AI掩码500或不可解码时保留原值。
- `/api/imaging/ai-source/<temp_id>`让模型获得同帧原图，避免误用缩略图；`/api/imaging/ai-status`只读模型状态，不触发设备检查。状态窗分别显示axle与ocr，探测失败显示未知。
- AI均为辅助：推荐、裁剪/OCR、车轴车厢及装载率不阻塞预览或最终提交。人工编辑（包括主动清空）由manualFields保护，当前检测内AI不能覆盖，普通同步也不能重算改回；原业务必填和人工草稿同步校验保留。提交、换图、重置及卸载会使对应旧请求结果失效。
- 草稿AI更新携带origin=ai、原版本、模型图片来源；后端事务内舍弃过期或被人工覆盖的AI值，正常人工更新照常保存。aiContext共享当前图片的轴数/来源及OCR完成状态，支持跨端牌色判型和刷新后补做未完成OCR。后端保存车型再次使用最新牌色。
- 相同文件内容及模型参数在同一后端进程合并推理，成功缓存120秒，32项/32MiB上限，失败不缓存。多进程没有分布式去重保证。正式裁剪返回共享URL，避免Base64裁剪输出挤占人工字段同步队列。
- 提交时可放弃等待悬挂的AI专用草稿请求，人工更新照常保存；迟到响应不再参与客户端确认。已发出的请求仍由后端会话、版本和人工保护校验。主证、挂车证与拼接图分别核对输出来源，人工补拍不能归为可丢弃的AI更新。历史车型/货箱回填也遵守人工主动清空保护。

## 本地验证
