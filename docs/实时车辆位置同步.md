# 实时车辆位置同步

2026-11-09：底部车辆移动动画和距离显示在全流程跟随雷达。

- `$VMRMC`及兼容JSON距离回调不再因未受理而退出；调度器总是更新当前距离并发送`radar_distance`。
- 未启动检测调度时，只同步位置，不执行距离设备动作、抬杆判定或自动抓拍。
- 已启动调度时按原业务规则处理，同一雷达帧只推送一次位置。
- 驳回、重置、提交后的空闲阶段仍接收新雷达数据。无有效正距离时沿用页面隐藏小车规则，不模拟移动或添加距离偏移。
- WebSocket新连接、重连或重新订阅时，回放5秒内最近的真实位置；超过5秒不回放旧数据。非法非有限距离不推送。
- 前端位置独立于预约流程数据，页面订阅晚于消息到达时可恢复本机5秒内缓存，受理/驳回/重置不清空位置。原轨迹映射、CSS移动过渡和下一动画帧合并更新保留。

验证：`tests/test_radar_realtime.py`覆盖未受理、受理后、停止调度后、真实VMRMC解析、零距离、非法距离、节流缓存、连接/重连/订阅回放。
