# 点云图片保存

`vehicle_inspections` 保存以下点云图片路径，图片内容在统一图片目录：

| 字段 | 内容 |
| --- | --- |
| `radar_3d_image_path` | 原有3D页面当前视角截图 |
| `radar_3d_top_image_path` | 同一LAZ帧的顶部XY正交投影 |
| `radar_3d_side_image_path` | 同一LAZ帧的侧面XZ正交投影 |

顶部、侧面由后端同一次LAZ解码生成，随检测会话持久化，PC/Pad恢复同一份图；新点云帧替换两图并清除旧3D截图，缺少的视图置空，避免混入上一帧。确认页和记录详情提供“当前视角 / 顶部 / 侧面”查看入口。提交时统一复制到`radar_3d`、`radar_3d_top`、`radar_3d_side`分类目录，数据库保存绝对路径，详情API转换为图片URL。客户端未传两新图时，带有效会话的提交使用共享草稿中的两张投影兜底。

升级数据库先执行`migrations/20261114_radar_3d_views.sql`，再重启新后端。脚本只新增两列及中文注释，可重复运行；历史记录默认空，不回填或修改旧图。本机可运行`venv/Scripts/python.exe tools/migrate_radar_3d_views.py`，现场发布在容器中执行同一SQL。

升级前正在检测的会话仍可通过已有`geometryUrl`恢复顶部/侧面图，无需重新采集。没有有效点云时图片留空。此功能不保存原始LAZ，不恢复已经删除的旧`radar_top_image_path`/`radar_side_image_path`/`radar_head_image_path`字段。
