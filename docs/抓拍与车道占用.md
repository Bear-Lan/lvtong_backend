# 抓拍与车道占用

2026-11-20：自动采集等待车道恢复；右侧手动拍照可继续，手动照片优先。

- 受理后、自动抬杆前，自动采集遵守当前调度器的占用判定；连续5帧距离达到27米或为0（无限远），且无入侵，才解除占用并放行。本轮未修改阈值。
- 车头、车顶的距离自动抓拍和光幕触发的车尾抓拍统一拦截。被阻止的阈值不标为已拍；恢复后仍须满足原距离条件，不在驶离区间后补拍。
- 右侧手动拍照及单张接口不因占用暂停；采集前后仍检查检测会话，已提交或切换检测的迟到照片丢弃。批量采集仍按自动流程检查占用，阻止时返回409。
- 当前检测内，手动确认或删除的照片按类别保护，解除占用后的自动照片不能覆盖。保护跨电脑/平板同步、刷新恢复；重置或换车后清空，其他未手动编辑的类别仍正常接收自动照片。
- 弹窗内已手动拍摄的内容保留，行驶证已手动删除的内容也不会被迟到同步重新填入；关闭或确认后写入共享草稿。
- 线扫车身采集的camcap=true、车身拉图启动、轮询请求和图像推送均检查占用。已经在途的RTSP/HTTP图像，如果期间发生占用或重置，则丢弃，不覆盖当前预览；恢复后可重新获取。
- 放行仍按原正常连续5帧逻辑，放行后不把车辆正常进入21米以内改判为占用。否则会错误阻止正常过车的车顶照。
- 不更改灯、闸、语音、LED、几何采集和X光机控制动作。

自动距离配置见`config/scheduler_config.json`：车头26.5～28.5米、车顶20～22.5米，车身图在23～28米进入轮询。线扫实际启采仍在正常抬杆时发送camcap=true。

隔离验证见`tests/test_capture_lane_guard.py`、`tests/test_inspection_session.py`；前端`tests/ai/sync-regression.cjs`及`tests/ai/real-sync.cjs`覆盖占用中手动拍照、恢复后的照片保护及双端刷新。测试不连接现场设备。
