# 预约海康无插件实时对讲

前端电脑/平板浏览器通过麦克风采集与 AudioWorklet 音频处理，使用已登录 JWT 连接 Socket.IO `/talk` 命名空间。后端读取 `cam_booking` 数据库凭据，独占该设备的 ISAPI TwoWayAudio 通道 1。浏览器不接触相机凭据，不安装海康本地插件。

视频仍使用原来的 H.265 → 服务端 H.264 → WHEP，不依赖音频开通成功；自动语音仍使用 UDP 组播中间件，不申请或抢占人工对讲通道。

## 使用

1. 通过受信任 HTTPS 打开前端，现场默认端口 5174。现场电脑可用 `https://localhost:5174`，其他终端使用证书 SAN 内可达的现场地址。
2. 在预约窗口点击“开始对讲”，或在主页底栏点击对讲图标后开始。首次允许浏览器麦克风权限。
3. 显示“实时对讲中”后双向收发。点击结束、关闭弹窗、离开页面或连接异常时释放麦克风和相机通道。首次开始不自动请求权限，也不自动播放，避免浏览器的手势限制。
4. 多终端同时开启时，后一个提示占用。单次连接最长10分钟；会话结束后可以重新点击连接。

采用现场相机当前报告的 G.711 A-law 或 μ-law，不修改相机编码配置。G.711 音频为 8kHz、单声道、每帧320字节（40ms）。浏览器按实际音频上下文采样率连续重采样、编码；下行解码后插值播放。未确认传输窗口最多24帧，后端待发送麦克风队列最多5帧，浏览器播放队列最多200ms，网络恢复时丢弃积压旧音频。

## 协议

- 连接 `/talk`：`auth: {token: JWT}`，无效或过期登录拒绝连接。
- `start`：ACK `{ok,error?}`，开通相机后推送 `ready: {codec,sampleRate,frameBytes,deviceId}`。
- `audio`：双向二进制 G.711 数据；上行必须固定320字节，双方 ACK 限制未确认帧数。
- `heartbeat`：浏览器2秒一次；8秒失联、JWT过期、10分钟上限或相机收发异常均结束。
- `stats`：每秒提供 `sentBytes/receivedBytes/microphoneBytes/droppedFrames` 供验证。`sentBytes` 包括维持连接的静音，须同时检查 `microphoneBytes`，不能把相机上传字节数当作麦克风已采集的证明。
- `stop` 或断开连接：异步关闭相机、释放独占锁；清理完成前拒绝新连接。
- `ended`：结束原因、字节数与 `cameraClosed` 关闭确认。

相机提前返回无长度的 HTTP 200 并继续接收上传体。使用独立 HTTPResponse 解析响应头，保留发送套接字，不能用会因 `will_close` 关闭连接的 `HTTPConnection.getresponse()`。收到 `/open` 的 sessionId 后带入音频 URI；下行 GET 持续到本次会话结束，不能收几帧后提前关闭。

## 验证

运行 `python -m unittest discover -s tests -v`；新增测试覆盖鉴权、抢占隔离、断线和失败回收、过期、队列窗口边界与海康提前响应兼容。音频编码向量与分块重采样测试位于前端 `tests/talk`。

现场联调须直接使用独立对讲入口，不能通过预约受理、放行、检测或射线流程间接测试。字节链路、浏览器音频处理测试与真实扬声器/麦克风试听应分别记录。
