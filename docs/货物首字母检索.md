# 货物关键词检索

`GET /api/dict/products?keyword=bc` 同时匹配品种名称、`variety_name_pinyin` 和别名，使用 PostgreSQL ILIKE，不区分大小写；bc、BC、bC结果一致。现有数据库的拼音字段已经是BC、DBC等首字母，无需新增依赖或修改数据库。

关键词内部三项为OR，农产品类型及显式variety_name/pinyin条件仍按AND组合；计数和分页共用同一个筛选器，保留原id排序及跨页选中行为。旧的独立pinyin查询也改为ILIKE，兼容数据库大写首字母。所有查询值继续参数绑定。

本地gcis只读验证：bc、BC、bC均查到大白菜、普通白菜、菠菜；名称搜索和别名搜索保留，分类与分页验证通过。前端提示可输入名称、别名或拼音首字母。
