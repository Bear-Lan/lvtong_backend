# 面板缩略显示与原图裁切

车身/透视的共享草稿继续保存原图URL，原图内容及提交路径不变。图片接收时复用成对预览，写入原图旁的`.preview.jpg`；旧会话缺少预览时首次访问生成。无需数据库迁移。

- `GET /api/panel-images/preview/<原图哈希文件名>`：最长边1600的JPEG，内容地址可缓存；仅允许共享图片目录哈希文件名。
- `POST /api/panel-images/crop`：需登录，参数`sourceUrl`、`displayWidth`、`displayHeight`及`x1/y1/x2/y2`。使用框选当时所见帧的原图地址和预览像素尺寸，映射原始像素，返回临时PNG URL；前端立即读取为独立数据，供右侧预览、追加、提交。
- PNG裁块不缩小，保留原始位深/通道；前端透视色阶和伪彩只作用于面板显示。
- gevent服务使用所属hub的线程池执行解码裁切，原生线程服务直接执行，不复用设备HTTP线程池。

验证：`python -m unittest tests.test_panel_preview -v`，覆盖预览尺寸/原图持久化、缓存清空及重建、老会话懒生成、原始像素裁切、反向/越界/非有限坐标、目录限制及登录认证。配合前端PC/Pad完整流程和慢帧专项；不发送现场控制命令。上游仍提供完整快照，实际帧率由设备采集、网络和处理共同决定。
